## Decisions taken at this gate

- **Output: raw node, no buffer.** Silicluster has not specified the output load. y has
  ≈ 300 kΩ output impedance and must be measured with ≥ 10 MΩ (≈ 2.8 % gain loss; linearity is
  unaffected). If Silicluster later specifies a heavier load, a buffer needs a core power cut first.
- **Core power kept as verified.** The 98.2 µW case combines the hottest, highest-supply corner
  with an assumed −20 % xhigh_po sheet resistance; SkyWater lists xhigh_po e-test specs as TBD.

## Carried into layout

- Mirror matching sets the weight σ: MF / XWS / XWK in common-centroid with dummies.
- R_in, R_k, R_out from interdigitated unit segments (also required by the 115 µm height).
- Cc MIM capacitors (metal 3–4) need gaps in the M4 power grid.
- Post-layout: re-check phase margin with extracted parasitics (pre-layout margin 71.7°).
- Simulation pitfall: the xhigh_po model allows spurious kV solutions; `neuron_tb.cir` detects
  and retries them automatically (see `docs/neuron-core.md`).
